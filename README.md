# Blood Report Management System

## About My Project

I made this project as my **Class 12 Computer Science project** using **Python and MySQL**.

This program helps to **store patient details and blood test reports** and also helps to **find abnormal values in blood reports**.

---

## Why I Made This

I made this project to:

- Learn how to connect Python with MySQL  
- Reduce manual work in managing reports  
- Store patient and blood report data in a computer  
- Help doctors and patients view reports easily  

---

## Tools I Used

- Python 3  
- MySQL  
- mysql-connector-python  

---

## Database

Database name: `blood_trial`

Tables used:

- `la` – Patient details  
- `bl` – Blood report details  
- `doc` – Doctor details  

---

## What My Program Can Do

My program has 3 parts:

1. Doctor – can view patient reports  
2. Patient – can view their own report  
3. Lab Admin – can add and update records
